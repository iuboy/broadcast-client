## [0.1.0] - 2025-02-27

### Added
- GitHub Actions CI/CD 工作流（build, dev-build, release）
- WebSocket 客户端连接到广播服务
- 音频处理和播放功能
- 应用配置管理
- 自动更新检查功能
- 多平台构建支持（Windows、macOS、Linux）
